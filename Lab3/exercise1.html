Exercise 1: Explore and Understand JSON Structure

Library Book JSON

The JSON data is organized as an object containing information about a book. The book in the file is Fantastic Mr. Fox. The data contains name/value pairs, arrays, objects, and nested structures.

Name/Value Pair

A simple name/value pair from the JSON is:

"title": "Fantastic Mr. Fox"

Object

The identifiers property contains an object:

"identifiers": {
    "goodreads": ["1507552"],
    "librarything": ["6446"]
}

Array

The publishers property contains an array:

"publishers": ["Puffin"]

Nested Structure

The JSON also contains objects nested inside the main book object. For example, first_sentence contains additional information: 

"first_sentence": {
    "type": "/type/text",
    "value": "Down in the valley there were three farms."
}

Overall Organization

The JSON begins with one main object. Inside the object are properties that store simple values such as text and numbers, arrays that contain collections of values, and nested objects that contain additional structured information.
